# Eventify 🎟️

O **Eventify** é uma aplicação web para criar convites digitais personalizados de forma simples e rápida.

## ✨ Funcionalidades

- Criação de convites para eventos.
- Personalização de cores e temas.
- Adição de imagem de capa.
- Pré-visualização em tempo real.
- Modo claro e escuro.
- Validação dos campos do formulário.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
